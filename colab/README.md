# Colab notebooks

Start with [`periodic_committor.ipynb`](periodic_committor.ipynb) for the full comparison workflow. The repository root then links the OU, double-well, and Duffing notebooks in reading order.

The repository is designed to be publicly readable. Setup cells clone or install public code and do not require a GitHub access token. Google Drive is used only when a notebook saves a long run for later inspection or resumption.

Choose the runtime before setup, edit the visible Python configuration, and run the cells in order. `quick` settings exercise the workflow. Paper-scale settings require substantially more computation and are intended for Colab or another suitable machine.
